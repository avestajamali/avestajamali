### Selected projects

- **[claude-notebook](https://github.com/avestajamali/claude-notebook)** — an Obsidian plugin (TypeScript, ~3,000 lines) that fuses a Markdown note with a live Claude agent: chat grounded in your notes, direct edits, Socratic quizzing, and automatic filing of dropped documents. Careful about security — read-only modes can't run a shell or touch the network.
- **[convert-to-markdown](https://github.com/avestajamali/convert-to-markdown)** — a Python engine that turns any Office/PDF document into clean Markdown at the lowest possible cost, escalating to page-level image rendering only where cheap local extraction fails.
